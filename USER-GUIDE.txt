Office Portable — local modified Craft builds

Word = WordCraft 0.18.1
Excel = GridCraft 0.19.1
PowerPoint = DeckCraft 0.18.1
PDF = PdfCraft 0.21.1

Названия выбраны для удобства. Это самостоятельные модифицированные проекты Craft,
не Microsoft Office. Оригинальные авторы, лицензии и ссылки сохранены в «О программе».
Исполняемые файлы локальной сборки не имеют цифровой подписи оригинального издателя.

Запуск: откройте Word\Word.exe, Excel\Excel.exe, PowerPoint\PowerPoint.exe или PDF\PDF.exe.
Office Setup.exe настраивает интеграцию с Windows для текущего пользователя.
Администратор и установка не нужны. Приложения по умолчанию подтверждаются в Windows.

«Добавить все программы» добавляет ассоциации «Открыть с помощью».
Галочка «Добавить документы в подменю “Создать”» добавляет пустые документы:
  Документ Word (.docx), Книга Excel (.xlsx), Презентация PowerPoint (.pptx), Документ PDF (.pdf).
Пустые документы встроены в Office Setup.exe. Самостоятельных команд «Открыть в …» нет.
Уже существующие чужие пункты «Создать» утилита не перезаписывает:
при конфликте можно снять галочку и добавить только ассоциации.

После перемещения комплекта повторите добавление из нового расположения.
Перед удалением выберите другие приложения по умолчанию и нажмите «Убрать интеграцию».

У каждой программы рядом с .exe находится Data:
  Settings — постоянные настройки интерфейса и приложения. Сохраняйте.
  User — личные словари, шаблоны, шрифты, языковые пакеты и цифровые ID. Сохраняйте.
  Recovery — восстановление несохранённых документов. Не чистите вслепую.
  Cache — воспроизводимый кэш. Можно очистить при закрытой программе.
  Logs — журналы. Можно очистить при закрытой программе, если не нужна диагностика.
  Runtime — служебные файлы открытой программы. Можно очистить только после закрытия.
  Temp — временные рабочие файлы. Можно очистить только после закрытия.

Установленные языковые пакеты Word находятся в User/LanguagePacks. Их настройки,
индексы, временные загрузки и блокировки разнесены по соответствующим папкам Data.

Имя автора новых документов по умолчанию — user. В Word нет поля инициалов,
аватар заменён на нейтральный силуэт. Данные авторов в старых документах не переписываются.
Модуль оригинального обновления удалён из сборки: обновляйте комплект целиком,
сохраняя свою Data. Репозиторий сборки: https://github.com/BLXCKBXXST/office-portable

Структура Data относится к файлам самих программ. Windows и драйверы самостоятельно ведут
системные журналы и кэш, которые находятся вне переносимой папки.
