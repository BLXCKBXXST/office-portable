# Office Portable

Переносимый комплект для Windows x64: **Word, Excel, PowerPoint и PDF**.

Это неофициальные модифицированные сборки открытых проектов **WordCraft, GridCraft, DeckCraft и PdfCraft**. Они не являются Microsoft Office и не связаны с Microsoft. Привычные названия выбраны для удобства; исходные авторы, ссылки и лицензии сохранены.

[Скачайте последнюю сборку](https://github.com/BLXCKBXXST/office-portable/releases/latest), распакуйте ZIP и запускайте программы из своих папок. Установка и права администратора не нужны. Сборки не имеют цифровой подписи оригинального издателя; контрольные суммы приложены к релизу.

**Office Setup.exe** добавляет приложения в «Открыть с помощью» и корректные пустые документы в подменю «Создать». Пункты «Открыть в …» не добавляются. Кнопки выбора приложения по умолчанию открывают нужную страницу Windows, где пользователь подтверждает выбор. Утилита также удаляет собственные записи интеграции, сохраняя документы.

У каждого приложения одинаковая структура **Data**:

| Папка | Содержимое |
|---|---|
| Settings | Постоянные настройки |
| User | Личные словари, шаблоны, шрифты, языковые пакеты, цифровые ID |
| Recovery | Восстановление несохранённых документов; не очищайте вслепую |
| Cache | Кэш |
| Logs | Журналы |
| Runtime | Служебные файлы работающего приложения |
| Temp | Временные рабочие файлы |

При обновлении сохраните свою Data. Кэш, журналы и временные файлы очищайте после закрытия приложений. Системные журналы и кэш Windows находятся вне переносимой папки. После переноса комплекта повторите регистрацию в Office Setup.

Имя автора по умолчанию — `user`. В Word убраны поле инициалов и аватар с буквами; используется нейтральный силуэт пользователя. Модуль оригинального обновления удалён, чтобы обновлялся весь изменённый комплект.

## Автосборка

GitHub Actions проверяет новые стабильные релизы исходных проектов каждые шесть часов; предусмотрен и ручной запуск. Проверка может запускаться с задержкой по правилам GitHub.

Новый релиз создаётся только после применения всех правок, успешной компиляции, проверок путей профиля, зависимостей Windows, CLI, пустых документов и тестов Office Setup в отдельной ветке реестра. В релиз не попадают пользовательские профили. Проверки интерфейса на hosted CI не выполняются.

Если upstream изменился несовместимо, сборка останавливается и новый релиз не публикуется. Последний готовый релиз остаётся доступен; изменения нужно адаптировать вручную. Сборочные задания имеют доступ только на чтение. Публикация выполняется отдельным заданием, которое не запускает собранные программы.

Исходные проекты: [WordCraft](https://github.com/storytold/wordcraft), [GridCraft](https://github.com/storytold/gridcraft), [DeckCraft](https://github.com/storytold/deckcraft), [PdfCraft](https://github.com/storytold/pdfcraft). Правки находятся в `patches/`, адаптированная существующая библиотека хранилища языковых пакетов — в `overlay/`. Авторские уведомления и лицензии исходных проектов сохраняются.

Код сборочных рецептов и правок распространяется под MIT OR Apache-2.0. Компоненты и данные сохраняют свои исходные лицензии.
