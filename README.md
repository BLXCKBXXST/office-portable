# Office Portable

Переносимый комплект **Word, Excel, PowerPoint и PDF** для Windows x64 на основе открытых проектов ArtCraft. Нужен, чтобы пользоваться офисными программами без установки и переносить их вместе с настройками на флешке.

Настройки и рабочие данные хранятся рядом с программами в `Data`. **Office Setup** настраивает ассоциации файлов и добавляет пустые документы в меню «Создать». Оригинальный модуль обновлений удалён; новые версии комплекта собираются через GitHub Actions.

[Скачать последнюю сборку](https://github.com/BLXCKBXXST/office-portable/releases/latest)

Оригиналы: [WordCraft](https://github.com/storytold/wordcraft) · [GridCraft](https://github.com/storytold/gridcraft) · [DeckCraft](https://github.com/storytold/deckcraft) · [PdfCraft](https://github.com/storytold/pdfcraft).

Неофициальная сборка, не Microsoft Office. Привычные названия выбраны для удобства. Авторские уведомления и лицензии сохранены; код правок и сборки — MIT OR Apache-2.0.
