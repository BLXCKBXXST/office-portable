# Office Portable

Офисные приложения ArtCraft, доработанные для переноса **вместе со всеми настройками**. Настройки, пользовательские данные, кэш, журналы и временные файлы программ хранятся рядом с ними, в одинаковой структуре `Data`.

Оригинальные portable-архивы уже позволяют запуск без установки. Наша сборка нужна для единого хранения данных всех четырёх приложений, привычных названий **Word, Excel, PowerPoint и PDF** и настройки ассоциаций и меню «Создать» через **Office Setup**. Оригинальный обновлятор удалён, чтобы не заменять изменённые программы; новые версии комплекта собираются через GitHub Actions.

[Скачать сборку](https://github.com/BLXCKBXXST/office-portable/releases/latest)

Оригиналы: [WordCraft](https://github.com/storytold/wordcraft) · [GridCraft](https://github.com/storytold/gridcraft) · [DeckCraft](https://github.com/storytold/deckcraft) · [PdfCraft](https://github.com/storytold/pdfcraft).

Неофициальная сборка, не Microsoft Office. Системные журналы и кэш Windows находятся вне `Data`. Авторские уведомления и лицензии сохранены; код правок и сборки — MIT OR Apache-2.0.
